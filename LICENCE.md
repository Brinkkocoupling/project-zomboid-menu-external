**Project Zomboid Menu External** is a comprehensive external menu for Project Zomboid Build 41 featuring item spawner, skill editor, teleport, god mode, and debug console.

## ✨ Features

### 🎮 Core Features
- God Mode — become invincible to zombies and hazards
- Item Spawner — spawn any item with quantity control
- Teleport — jump to any map coordinate or saved location
- Skill Editor — set any skill level and XP instantly
- No Hunger/Thirst — disable survival needs

### 🎨 Cosmetics & Unlocks
- Unlock All Traits — access every positive trait without points
- Vehicle Spawner — spawn any vehicle with full condition
- Instant Build — construct structures without materials

### 🏋️ Practice & Training
- Debug Console — execute game commands and scripts
- Time Control — change time of day and season
- Zombie Population Editor — adjust spawn rates and behavior
- Unlimited Carry Weight — remove inventory limits
